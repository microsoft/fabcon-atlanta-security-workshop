# FabCon Atlanta 2026 – Microsoft Fabric Security Workshop

This repository contains the materials for the **Microsoft Fabric Security Workshop** delivered at **FabCon / SQLCon Atlanta 2026** by **Vengatesh Parasuraman and Amanjeet Singh**

The workshop is designed to help customers and partners understand and apply **security, identity, and network protection concepts in Microsoft Fabric**, with a strong focus on real‑world enterprise scenarios and best practices.

---

## 📘 Workshop Overview

The Fabric Security Workshop is a **hands‑on, scenario‑driven** session that walks participants through key security capabilities in Microsoft Fabric, including:

- Identity and access management
- Inbound and outbound network security
- Secure data access patterns
- Workspace governance and OneLake security

The workshop is structured into **four modules**, each building on the previous one.
